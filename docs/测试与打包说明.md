## 一、打包成 exe 后是否还需要固定环境？

**不需要。** `electron-builder` 打出的 exe 会把 Chromium 与 Node 运行时一起打进包里，目标机器不用装 Node、pnpm 或任何运行库，双击即用。

需要知道的三个点：

| 事项 | 说明 |
| --- | --- |
| 包体积 | 安装包约 70–90MB，解包后约 150–200MB（自带运行时，属正常） |
| 首次运行拦截 | 未做代码签名，Windows SmartScreen 会提示"未知发布者"，点「更多信息 → 仍要运行」即可，之后不再提示 |
| 数据位置 | 设置、黑名单、路径偏好存在 `%APPDATA%\TavernLib`，升级/覆盖安装不丢 |

## 二、未打包阶段能怎么测（4 + 1 种）

| # | 方式 | 命令 / 操作 | 能验证什么 | 局限 |
| --- | --- | --- | --- | --- |
| 1 | 开发热更新 | `pnpm dev` → 浏览器打开 `http://localhost:5199` | 界面、交互、导入解析、ZIP 生成逻辑（走浏览器下载）、多选/框选/黑名单 | 无系统文件对话框；无跨域代理，连不了真酒馆 |
| 2 | 静态产物预览 | `pnpm build` → `pnpm preview`（`http://localhost:4180`） | 同上，且加载方式与打包后一致，可提前发现打包才暴露的资源路径问题 | 同 1 |
| 3 | **Electron 直跑（不打包）** | `pnpm build` → `pnpm app` | 真实窗口、系统保存对话框、ZIP 写盘、主进程 HTTP 代理（绕 CORS/CSRF）、外部浏览器打开 DC | 需要本机 Electron 能正常启动 |
| 4 | **免安装绿色目录（最接近成品）** | `pnpm pack:dir` → 产物在 `release\win-unpacked\TavernLib.exe` | 验证"换电脑免环境"：把整个 `win-unpacked` 目录拷到另一台机器，双击就能跑 | 无安装器、无开始菜单项 |
| 5 | 自动化 UI 快照（无需显示器、无需 Electron） | `pnpm build` → 起静态服务 → Chrome/Edge 无头模式 `--screenshot`，可加 `?scene=multi｜import｜settings｜check｜detail` 直达指定界面状态 | 排版回归、五种界面状态的批量截图验收 | 只验证渲染，不验证 Electron 能力 |

推荐组合：日常改界面用 1；改主进程/文件对话框用 3；每隔一版用 4 做一次"换机免环境"验证。
