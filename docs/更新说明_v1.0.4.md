# 洛书匣 v1.0.4 更新说明

发布日期：2026-11-14

本次更新围绕「新建到酒馆」这一核心动作重新梳理了行为，"新建"就是新建，不再需要用户做任何额外选择。

## 本次改动

- **「新建到酒馆」改为直接新建**：点一下就会把角色卡真实写入酒馆，不再弹出同族处理方式的三个选项，也不再需要选择或确认副本。少一步选择，多一步直达。
- **同名时自动另起基名，绝不覆盖**：酒馆里已经有同名角色时，新建会使用一个独立的基名写入（例如「张三 新」「张三 新2」），原有角色卡保持原样、不被改写。
- **支持版本记录多选批量新建**：在版本记录里勾选多条后点「新建到酒馆 N 项」即可一次性全部新建，点击即执行，无需逐条确认。
- **对比区显示卡内真名与来源标签**：对比区域展示角色卡内部的真实角色名与来源标签，便于确认哪一份是自己要的那张卡，而不是只能看到文件名。
- **保留缩略图与自动补世界书**：新建进酒馆的角色卡仍带缩略图，并自动补齐缺失的世界书信息，观感与后续可用性与之前一致。
- **批量与单条口径完全一致**：批量新建逐条走与单条新建完全相同的流程，结果口径统一，不会出现单条和批量行为不一样的情况。

## 升级方式

直接运行 `洛书匣 Setup 1.0.4.exe` 覆盖安装即可，原有资料库与设置会保留。

## 说明

- 「更新到酒馆」的用法与之前保持一致：当酒馆里存在多份同名角色卡时，仍会请你确认要更新的是哪一份。
