# 洛书匣 v1.0.6 更新说明

发布日期：2026-11-15

本次更新修复界面观感与两处功能缺陷，重点是让「检查更新」的结果一眼可见、让预设与美化的对比真正能用。

## 本次改动

- **日间模式详情页左侧配色统一**：修复详情页左侧栏在日间模式下仍然是深灰一块、与白色主区割裂的问题。左侧栏背景、封面描边与内阴影、无封面占位块渐变、占位首字颜色、备注框底色全部改为跟随主题切换，日间为冷白渐变，与整体界面一致。
- **分类页签显示更新角标**：检查更新完成后，顶部各分类页签会直接显示该分类下待更新条目数量的数字角标（超过 99 显示 99+），并带悬停提示。不必再切进分类才能发现有更新。
- **预设与美化对比功能修复**：修复对比功能对预设和美化不生效的问题，具体包括：
  - 美化（主题）此前完全没有进入扫描链路，现已补上扫描与结果展示；
  - 酒馆侧条目此前没有内容指纹，导致「是否与某个版本一致」永远判为不一致，现补算指纹后再比对；
  - 归在「其他」分类的预设与美化此前被一律当作世界书计算，现按世界书、预设、美化三种算法分别比对；
  - 召回同名条目时不再因 `·V1.4.0`、`(1)`、`.json` 等尾缀而匹配失败，改为名称归一化、文件名、已登记目标路径、内容指纹逐级召回；
  - 扫描失败（例如主题目录不存在）不再静默吞掉，会在条目上给出失败原因提示。
